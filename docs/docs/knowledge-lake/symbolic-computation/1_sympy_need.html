Symbolic Mathematics (Need)

1 What to Expect in This Chapter

There are many situations where we would like to manipulate mathematics symbolically rather than numerically. Packages such as Mathematica and Maple can perform this symbolic magic, but they are expensive. Fortunately, Python has an open-source package called SymPy that brings powerful symbolic manipulation to your fingertips.

These notes introduce symbolic mathematics using SymPy. The examples are deliberately short. Please refer to SymPy documentation and the tutorials to appreciate the full power of what SymPy can do.

Also, note that SymPy offers a live shell that is handy for ‘quick and dirty’ calculations when you are lazy to open up a file.

Point to Ponder

Now that we have Large Language Models (LLMs) at our beck and call, it is tempting to use them for symbolic manipulation too. While this may sometimes work, you have no guarantee that what the LLM outputs is correct—unless it has been specifically designed for mathematical reasoning. My advice is to tread carefully.

2 Setting Up

2.1 Install and Import

You can install SymPy in the usual way (e.g. with pip or conda) and then import it as follows:

import sympy as sp

2.2 Pretty Printing

3 Basics

3.1 Declaring Symbols

Before you can use variables in SymPy, you need to declare them as symbols. This step only needs to be done once per session.

x, y, z = sp.symbols('x y z')

Declaring symbols gives you full control over how they behave mathematically and how they are displayed. For example, you can specify whether a symbol should be real, positive, or an integer.

x = sp.symbols('x', real=True, positive=True)
a, b, c = sp.symbols('a b c', real=True, positive=True)

3.2 Expansion

sp.expand((x + y + z)**3)

\[x^{3} + 3 x^{2} y + 3 x^{2} z + 3 x y^{2} + 6 x y z + 3 x z^{2} + y^{3} + 3 y^{2} z + 3 y z^{2} + z^{3}\]

3.3 Square roots and radicals

show(sp.sqrt(8*x + 4*y + 2*z))

\[\sqrt{8 x + 4 y + 2 z}\]

3.4 Substitution

hahaha = sp.symbols('hahaha')
(sp.cos(x)).subs(x, hahaha)

\[\cos{\left(hahaha \right)}\]

3.5 Simplification

sp.simplify(sp.sin(x)**2 + sp.cos(x)**2)

4 Solving Equations

a, b, c = sp.symbols('a b c')
show(sp.solve(a*x**2 + b*x + c, x))

\[\left[ \frac{- b - \sqrt{- 4 a c + b^{2}}}{2 a}, \ \frac{- b + \sqrt{- 4 a c + b^{2}}}{2 a}\right]\]

5 Calculus

5.1 Differentiation

sp.diff(x**4, x)

\[4x^{3}\]

Differentiate multiple times:

sp.diff(x**4, x, 3)

\[24x\]

Partial derivatives

sp.diff(x*y*sp.sin(x), x)  # ∂/∂x

\[xy\cos(x) + y\sin(x)\]

sp.diff(x*y*sp.sin(x), y)  # ∂/∂y

\[x\sin(x)\]

5.2 Integration

Indefinite integrals

sp.integrate(a*sp.exp(-(x-b)**2/c**2), x)

\[\frac{ac}{2}\sqrt{\pi}\,\operatorname{erf}\!\left(\frac{x-b}{c}\right).\]

Definite integrals

show(sp.integrate(a*sp.exp(-(x-b)**2/c**2), (x, -1, 1)))

\[\frac{\sqrt{\pi} a c \operatorname{erf}{\left(\frac{1 - b}{c} \right)}}{2} - \frac{\sqrt{\pi} a c \operatorname{erf}{\left(\frac{- b - 1}{c} \right)}}{2}\]

show(sp.integrate(sp.exp(-x**2 - y**2), (x, -sp.oo, sp.oo), (y, -sp.oo, sp.oo)))

\[\pi,\]

The latter equals \(\pi\) as expected for the Gaussian integral in two dimensions.

Leave integrals unevaluated

sp.Integral(sp.exp(-x**2 - y**2), (x, -sp.oo, sp.oo), (y, -sp.oo, sp.oo))

\[\int_{-\infty}^{\infty}\int_{-\infty}^{\infty} e^{-x^{2}-y^{2}}\,dx\,dy.\]

6 Some Exercises

Here are some straightforward exercises to get you warmed up to SymPy.

Exercise 1 (Gaussian distribution in SymPy)

Define a Gaussian function in SymPy of the form

\[ f(x) = \frac{1}{\sqrt{2\pi}\,\sigma} \exp\left[-\frac{(x-\mu)^2}{2\sigma^2}\right], \]

where \(\mu\) is the mean and \(\sigma\) is the standard deviation.

  1. Use .subs() to substitute \(\mu = 0\) and \(\sigma = 1\), corresponding to the standard normal distribution.
    Evaluate the function at \(x = -1, 0,\) and \(+1\).

  2. Compute the integral of \(f(x)\) over the entire real line,

    \[ \int_{-\infty}^{\infty} f(x)\, dx, \]

    and check that the result is 1.

  3. Verify the well-known \(68\)–\(95\)–\(99.7\) rule for the Gaussian distribution by using sp.N() to evaluate the probability contained within one, two, and three standard deviations of the mean:

    \[ \int_{\mu-\sigma}^{\mu+\sigma} f(x)\, dx, \qquad \int_{\mu-2\sigma}^{\mu+2\sigma} f(x)\, dx, \qquad \int_{\mu-3\sigma}^{\mu+3\sigma} f(x)\, dx. \]

    Note: You do not need to assign specific values to \(\mu\) and \(\sigma\) for this task.

Exercise 2 (Averages)

  1. Average value of a function

    1. The average value of a function over an interval \([a,b]\) can be interpreted as the constant value that produces the same total area under the curve as the original function.

      Using this idea, show that the average of a function \(f(x)\) is given by

      \[ \langle f(x) \rangle = \frac{1}{b-a} \int_a^b f(x)\,dx . \]

      Here we use the notation \(\langle \cdot \rangle\) to denote the average.

    2. Use SymPy to compute the following averages. For each case, choose a logical interval (for example, a full period of the function) and justify your choice.

      1. \(\langle \cos x \rangle = 0\)
      2. \(\langle \sin x \rangle = 0\)
      3. \(\langle \cos^2 x \rangle = \frac{1}{2}\)
      4. \(\langle \sin^2 x \rangle = \frac{1}{2}\)
      5. \(\langle \cos^2(kx) \rangle = \frac{1}{2}\)
      1. \(\langle \sin^2(kx) \rangle = \frac{1}{2}\)
      2. \(\langle \cos^2(\omega t) \rangle = \frac{1}{2}\)
      3. \(\langle \sin^2(\omega t) \rangle = \frac{1}{2}\)
      4. \(\langle \cos^2(kx-\omega t) \rangle = \frac{1}{2}\) (time average)
      5. \(\langle \cos^2(kx-\omega t) \rangle = \frac{1}{2}\) (space average)

Exercise 3 (EM Wave Intensity)

  1. Electromagnetic wave intensity

    An electromagnetic wave consists of oscillating electric and magnetic fields, which can be written as

    \[ E(x,t) = E_0 \cos(kx-\omega t), \]

    \[ B(x,t) = B_0 \cos(kx-\omega t), \]

    where \(E_0\) and \(B_0\) are the field amplitudes, \(k\) is the wavenumber, and \(\omega\) is the angular frequency.

    These quantities are related by

    \[ E_0 = \left(\frac{\omega}{k}\right) B_0, \qquad c = \left(\frac{\omega}{k}\right) = \frac{1}{\sqrt{\mu_0\epsilon_0}}, \]

    where \(\mu_0\) and \(\epsilon_0\) are constants called the permeability and permittivity of free space. These are related to how strongly electric and magnetic fields can be created in vacuum.

    1. The intensity of an electromagnetic wave is given by

      \[ I(x,t) = \frac{E(x,t)B(x,t)}{\mu_0}. \]

      Write down the explicit expression for the instantaneous intensity of the wave at position \(x\) and time \(t\).

    2. In practice, it is more useful to consider the average intensity of the wave over one oscillation period.

      With the help of SymPy, compute the time-averaged intensity \(\langle I \rangle\) and show that it is given by

      \[ \langle I \rangle = \frac{1}{2}\epsilon_0 c E_0^2 . \]

Exercise 4 (Who Satisfies the Wave Equation?)

We recall the wave equations in one and three dimensions.

1D wave equation:

\[ \frac{\partial^{2} u}{\partial x^{2}} = \frac{1}{v^{2}} \frac{\partial^{2} u}{\partial t^{2}} \]

3D wave equation:

\[ \frac{\partial^{2} f}{\partial x^{2}} + \frac{\partial^{2} f}{\partial y^{2}} + \frac{\partial^{2} f}{\partial z^{2}} = \frac{1}{v^{2}} \frac{\partial^{2} f}{\partial t^{2}} \]

where \(v\) is the speed of the wave.

  1. Consider

    \[ f(x,t) = A \sin(kx-\omega t). \]

    1. Use SymPy to compute the LHS and RHS of the 1D wave equation and show that \(f(x,t)\) satisfies it.

    2. Conclude that the wave speed is

      \[ v = \frac{\omega}{k}. \]

  2. Consider

    \[ f(x,y,z,t) = A \sin(k_xx+k_yy+k_zz-\omega t). \]

    1. Use SymPy to compute the LHS and RHS of the 3D wave equation and show that this function satisfies it.

    2. Conclude that the wave speed is

      \[ v = \frac{\omega}{k}, \qquad k = \sqrt{k_x^2+k_y^2+k_z^2}. \]

    3. In what direction is the wave propagating?

      Hint: Consider special cases such as:

      • \(k_y = k_z = 0\), \(k_x \neq 0\)
      • \(k_z = k_x = 0\), \(k_y \neq 0\)
      • \(k_x = k_y = 0\), \(k_z \neq 0\)

  3. Consider

    \[ f(r,t) = \frac{A}{r}\sin(kr-\omega t), \qquad r = \sqrt{x^2+y^2+z^2}. \]

    1. Use SymPy to compute the LHS and RHS of the 3D wave equation and show that this spherical wave satisfies it.

      Hint: Do not panic if you obtain a messy expression on the left-hand side. Use sp.cancel() in SymPy to simplify by cancelling common factors.

    2. Conclude that the wave speed is

      \[ v = \frac{\omega}{k}. \]

    3. In what direction is this wave propagating?
